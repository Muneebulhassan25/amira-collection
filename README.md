# Trendy Nisa Rebuild

An original ecommerce application foundation built with React, JavaScript, Vite, and Tailwind CSS. This project is inspired by a general ecommerce shopping experience; it is not affiliated with or a reproduction of any other store.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Setup
From this project folder, install dependencies:

```sh
npm install
```

## Development
Start Vite's local development server:

```sh
npm run dev
```

Open the local address printed in the terminal. Vite refreshes the page as files change.

## Production build
Create an optimized build in `dist`:

```sh
npm run build
```

Preview that build locally:

```sh
npm run preview
```

## Project map
- `src/components` — reusable interface components
- `src/pages` — route-level screens (to be added)
- `src/data` — placeholder and catalog data
- `src/utils` — shared helpers
- `src/styles` — global styles and Tailwind entry
- `AGENTS.md` — conventions for future coding agents
- `PROJECT_STATUS.md` — current milestone and handover checklist

## Handover
This is the foundation milestone only. There is no catalog, cart, checkout, account system, backend, or deployment setup yet. See `PROJECT_STATUS.md` for the suggested next steps. Use original or properly licensed content for all future product copy and imagery.
